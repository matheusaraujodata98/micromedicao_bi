# Analise Exploratoria MicroEdicao

## Descrição do Projeto
Este projeto realiza uma análise exploratória de dados de micromedição, com foco em identificar padrões de consumo, anomalias e tendências. Ele utiliza notebooks Jupyter para análise e visualização de dados, e os resultados são preparados para integração com o Power BI.

## Estrutura do Projeto

- **data/**: Contém os dados utilizados no projeto.
  - **raw/**: Dados brutos.
  - **processed/**: Dados tratados.
  - **output/**: Resultados gerados, incluindo gráficos e tabelas.
- **notebooks/**: Notebooks Jupyter com as análises realizadas.
- **output/**: Resultados finais e relatórios.
- **src/**: Código-fonte do projeto.

## Notebooks

- `analise_exploratoria.ipynb`: Notebook principal com a análise exploratória.
- `analise_comercial2.ipynb`: Análise complementar.
